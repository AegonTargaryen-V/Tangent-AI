=== BLENDER 5.x SHADER NODE REGISTRY & SYNTAX REFERENCE ===
Usage: nodes.new(type="<IDNAME>")
Rule 1: Never use ShaderNodeTexMusgrave (replaced by ShaderNodeTexNoise).
Rule 2: Never use ShaderNodeMixRGB (use ShaderNodeMix with data_type='RGBA').
Rule 3: Always link using: links.new(node_source.outputs["<Output>"], node_target.inputs["<Input>"])

--------------------------------------------------------------------------------
4. COLOR & CONVERSION NODES
--------------------------------------------------------------------------------
IDNAME: ShaderNodeValToRGB (Color Ramp)
Inputs:
  - "Fac" (Float)
Outputs:
  - "Color" (Color)
  - "Alpha" (Float)
Accessing Elements in bpy:
  - node.color_ramp.interpolation = 'LINEAR' | 'CONSTANT' | 'EASE' | 'B_SPLINE'
  - node.color_ramp.elements[0].position = 0.0
  - node.color_ramp.elements[0].color = (r, g, b, a)
  - node.color_ramp.elements.new(position=0.5)

IDNAME: ShaderNodeMix (Universal Mix)
Inputs (RGBA mode):
  - "Factor" (Float)
  - "A" (Color)
  - "B" (Color)
Outputs:
  - "Result" (Color)
Properties:
  - data_type = 'RGBA' | 'FLOAT' | 'VECTOR'
  - blend_type = 'MIX' | 'DARKEN' | 'MULTIPLY' | 'BURN' | 'LIGHTEN' | 'SCREEN' | 'DODGE' | 'ADD' | 'OVERLAY' | 'SOFT_LIGHT' | 'LINEAR_LIGHT' | 'DIFFERENCE' | 'SUBTRACT' | 'DIVIDE'
  - clamp_factor = True | False

IDNAME: ShaderNodeRGBToBW
Inputs:
  - "Color" (Color)
Outputs:
  - "Val" (Float)

IDNAME: ShaderNodeInvert
Inputs:
